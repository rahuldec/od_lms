# ODTED LMS

A learning and trainee-management platform built for real organizational training workflows.

## What it does

ODTED LMS helps manage the complete trainee journey — from batches and learning levels to assignments, assessments, progress and performance.

### Core features

- 🎓 Trainee and batch management
- 📚 Learning-level progression
- 📝 Assignment and assessment tracking
- 📈 Progress timelines and admin analytics
- 😊 CSAT and performance tracking
- 👤 Trainee and administrator dashboards
- 🗂️ Configurable trainee information
- ⚡ Data caching and request de-duplication
- 🔎 Production-focused data consistency and validation

## Why I built it

This project grew from a real operational need rather than a tutorial or demo application. The goal is to turn a training process that previously depended on spreadsheets and manual follow-ups into a structured system with a reliable source of truth.

## Engineering focus

The project has evolved beyond UI development into areas such as:

- State and historical-data consistency
- Performance optimization
- API/request management
- Reusable React components
- Edge-case handling
- Admin analytics
- Regression prevention and testing

## Tech Stack

- **Frontend:** React, TypeScript
- **Backend/Data:** Supabase
- **Tooling:** Vite, Git, GitHub
